6) GITHUB PAGES YAYIN
==================================================
1. Bu klasörü GitHub deposu yapın (veya mevcut depoya push).
2. Settings → Pages → Source: Deploy from a branch → main / root.
3. CNAME dosyası zaten www.antalyamodernmermer.com.tr yazıyor.
4. Alan adı DNS (Google Domains / Natro / Türk teslimci):
   A kaydı GitHub Pages IP’leri veya
   CNAME: www → <kullanici>.github.io
   Apex (@) için ALIAS/ANAME veya GitHub A kayıtları.
5. HTTPS’i Pages ayarından zorunlu kılın.
6. Google Search Console’a sitemap ekleyin:
   https://www.antalyamodernmermer.com.tr/sitemap.xml
7. Google İşletme Profili web sitesini yeni adrese kilitleyin (NAP aynı kalsın).

Yerelde önizleme:
  klasörde: python -m http.server 8080
  tarayıcı: http://127.0.0.1:8080/
